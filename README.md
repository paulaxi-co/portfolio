# Paula XI — Personal Portfolio

A polished, human-centered portfolio showcasing my work in Product Design, UX/UI, and digital experiences.  
Built to be fast, clean, intentionally simple, and fully responsive across phone, tablet, laptop, and desktop widths.

## Responsive behavior

- Accessible mobile navigation with keyboard support.
- Fluid typography and layouts without horizontal overflow.
- Responsive Home, About, Projects, case-study, Contact, and Footer sections.
- Project cards and imagery adapt to the available screen size.

## Dependencies

- Node v20 or newer
- Yarn 1.22.22 (managed through Corepack)

## Installation

1. Install dependencies using yarn

```bash
corepack yarn install
```

2. Run development server

```bash
corepack yarn dev
```
